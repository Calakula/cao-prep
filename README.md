# COA Prep ♥

Сайт для подготовки к квизам: Quiz 1–8, Midterm, Endterm (Variant 1 и 2) + общий тест.
Чистый HTML/CSS/JS — без сборки и зависимостей.

## Деплой на GitHub Pages
1. Создай репозиторий на github.com (например `coa-prep`).
2. Загрузи **содержимое этой папки** в корень репозитория (кнопка *Add file → Upload files*, перетащи все файлы и папки `css`, `js`, `img`).
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save*.
4. Через 1–2 минуты сайт будет на `https://<твой-ник>.github.io/coa-prep/`.

## Фото
- Главное фото в сердечке: `img/us1.jpg` (замени файл на другое с тем же именем).
- Ещё фото: положи `img/us2.jpg`, `img/us3.jpg`, `img/us4.jpg` — появятся маленькими сердечками под текстом.

## Как добавить/исправить вопросы
Всё лежит в `js/data.js`. Формат: `M(вопрос, [варианты], "правильный")`, `MS(...)` для нескольких ответов.
